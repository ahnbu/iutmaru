# ㅋㅁ — 커밋하고 올리기

## 순서

1. `git status --short` 와 `git diff --stat` 으로 **뭐가 바뀌었는지** 본다.
2. 바뀐 것을 보고 **한국어 한 줄**로 커밋 메시지를 짓는다.
   - 무엇을 왜 바꿨는지가 드러나게 쓴다. 파일 이름 나열은 하지 않는다.
   - 예: `사진 업로드를 로그인한 사람만 되게 바꿈`
3. `git add -A` → `git commit` → `git push`
4. 올라간 뒤 **커밋 해시와 메시지**를 사용자에게 알려준다.

## 지킬 것

- `.env` 는 절대 올리지 않는다. `.gitignore` 에 있는지 먼저 본다.
- 바뀐 것이 없으면 커밋하지 않고 "올릴 게 없습니다" 라고만 말한다.
